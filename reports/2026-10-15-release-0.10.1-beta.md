# Scavenger Sense 0.10.1 beta — release inspection, 2026-10-15

The author requested **0.10.1 beta** for the combined package and a GitHub push.
This includes all unpublished development work previously labelled 0.10.0–0.10.4;
the version change does not revert features. Earlier dated reports retain their
original numbers as inspection history. No Nexus upload or comment was made.

## Track appearance

The existing Tracks -> Drawing -> Drawn as -> Footprints option already draws
alternating prints. The KShakes preset already selected it. There was no image
file to replace because both chevrons and footprints were drawn procedurally.

- Added optional `[Tracks] printTexture`, exposed as Footprint PNG. A transparent
  square right-print PNG, toes up, lives beneath ScavengerSense/icons. The
  render thread uses the existing texture cache, or the old shape if loading
  fails. Geometry rotates with travel; the left print mirrors the UVs.
- Added `guideLine` / Connect lit tracks to disable the faint joining glow.
  Both fields retain the previous appearance by default: empty PNG, line on.
  Existing print size/spacing, trail colour, fade and recording limits apply.
- The custom installer now offers chevrons or footprints. Every route's
  display guide mentions these controls; English/Chinese copy, translation
  template, user guides and all three presets include the new fields.
- No boot artwork is bundled, no per-species image selection is implemented,
  and these remain projected tracking overlays rather than terrain decals.
  Replacing a cached image requires restarting Skyrim.

## Validation

- Release x64 built using `tools/build.ps1 -Test`; all seven CTest suites passed.
  47 feature checks include the new settings round trip and legacy defaults.
  803 display checks include footprint orientation, square aspect and left UV
  mirroring in five directions, plus the prior smoothing/equipment checks.
- Runtime probes classify 1.5.97 as SE, 1.6.1170 and 1.7.104 as AE. The last
  checks production filename selection and format-5 reading using synthetic
  data. These executables do not run Skyrim or SKSE.
- The compiled SKSE metadata, CMake project and FOMOD both declare 0.10.1.
  The PE has x64 SKSE exports, release CRT imports and all 75 framework imports
  present in the user's updated framework DLL.
- ImGui 1.90.8 docking host/compiler layouts match: IO 14616, Style 1140,
  Vec2 8, Vec4 16, DrawVert 20, DrawIdx 2. Framework ABI guard tests pass.
- 642 menu strings have Chinese translations, with 128 historical keys retained.
  All 923 distinct Chinese ideographs in the translation file are present in
  the bundled font. Menu widget-ID checks pass.
- FOMOD validates against ModConfig5.0.xsd. 106 routes and 230 production config
  loads pass, including menu/installer preset parity, the new style choices and
  personal-INI precedence. There are no selected payload collisions.
- `tools/package_release.py` compares source/build/FOMOD versions, built/payload
  DLL bytes, ESP bytes, every ZIP member against the generated tree and CRCs.
  The generated tree contains 38 payload folders and 70 files.
