## Changes corresponding to the six feedback items

1. HUD suppression now leaves the vanilla movie alive and masks selected child
   clips. Eighteen independent controls include compass, system messages,
   subtitles, notifications, crosshair and each vanilla resource meter.
   Custom clip paths support HUD replacers. Movie-specific alpha snapshots
   are restored when suppression changes, and discarded on a movie replacement.
2. Translation packs are discovered from `ScavengerSense_<language>.ini`
   carrying `[Translation]`; a rescan reloads text. The 626-string English
   template, UTF-8 guide and append-only merge tool enable document-only
   translations. Existing Chinese entries and old keys are preserved.
3. CommonLibSSE-NG is pinned to released 12.1.0, commit
   `8ffc2b74af015f837de53cc02b0cb470a15678e4`. It classifies 1.6+ as AE,
   chooses `versionlib-*.bin` and reads format 5. Relations now uses
   `SkyrimVM::GetVMRuntimeData().impl` rather than a fixed-layout member.
   spdlog is 1.17.0 (`79524ddd08a4ec981b7fea76afd08ee05f83755d`);
   DirectXTK is `524c655ee0b69c33f6dfec81878596b131f79671` (2026-10-06).
   rapidcsv was already at latest tag 9.07. The cimgui ABI remains pinned to
   the working framework interface. Legacy SMF submodule heads had no newer
   changes; they are not substituted for the installed 3.x runtime.
4. The installer begins with English/Chinese selection. Subsequent pages use
   that language and have mutually exclusive, language-scoped flags.
   `fomod/installer_chinese.json` retains the Chinese copy across builds;
   missing entries fail generation. Language/control fragments load after
   preset fragments. A personal INI still has highest precedence.
5. NPC numbers are no longer accidentally inside the “Raise a bar” callback.
   Current, current/max and percent apply to sweep and combat bars. Number
   centring/size, player/NPC × health/magicka/stamina dimensions/offsets and
   PNG fill/background/frame layers are configurable. All three draw contexts
   use one renderer. Missing artwork falls back; the fill crops UVs with the
   value and respects the reduced maximum. Large custom layouts are freeform.
6. The old arousal droplet was procedural geometry. The new outline has
   multiple flame tongues and can be replaced by a PNG. Press/hold sensing
   already existed; the default shared-key layout reserved those gestures
   for tracking. New shortcuts and installer options switch to a separate
   tracking key, so single-press sensing has no double-tap delay.

Regeneration-per-second numbers and complete TrueHUD feature parity are not
implemented. Resource values and skin/layout controls are implemented.

## Validation and its limits

- Native Release x64 build passed with MSVC 14.44 and the existing Ninja cache.
- CTest: 4/4 passed. The feature executable performed 32 checks covering
  config round trips, six independent styles, fragment precedence, invalid
  numeric values, UTF-8/BOM discovery, escaped keys, fallback and HUD restoration.
- Three real PE executables with version resources exercised the linked
  production CommonLib: 1.5.97 -> SE / VM +0x200; 1.6.1170 -> AE / VM +0x200;
  1.7.104 -> AE / VM +0x210. The 1.7.104 executable also resolved two IDs
  through the production filename selection and format-5 loader using a
  synthetic file confined to `plugin/build/test-fixtures`.
- The DLL's x64 architecture, SKSE exports and compiled 0.10.0.0 metadata
  passed PE inspection without loading the plugin. All 73 imported framework
  symbols and `RegisterHudElement` exist in the installed SMF 3.14 DLL.
- 626 current translation keys are present in Chinese; 126 older entries are
  retained. Merge was run twice: 623 additions on the first test, 0 on the
  second, with existing translated text/comments retained.
- ImGui widget ID checker passed. Installer validator and 102 simulated
  language/preset/control/option routes passed without selected-file collisions.
- The generated installer passed the actual ModConfig 5.0 XSD, fetched from
  `foesmm/fomm`, `flmm/data/ModConfig5.0.xsd`, via GitHub's contents API.
- ZIP CRC and all 64 members were compared byte-for-byte with the generated
  FOMOD tree. The packaged and installed DLL match the tested build.

These are compilation, native offline and XML/data checks. No BodySlide preview
or Skyrim session was run. In-game HUD flicker/restoration, custom PNG rendering,
font coverage, arousal icon appearance, input behaviour, and actual SKSE/game
startup on 1.5.97/1.6.1170/1.7.104 remain unverified. A generic 1.6.1170 DLL
failure cannot be attributed to the same cause without its exact loader error.
Other mods hiding the HUD parent can still hide retained parts. Unknown clips
are left alone. PNGs are cached; replacing a loaded/missing image needs restart.

## Deployment and preservation

Re-read the selected profile (`J61-BFCO`), modlist and plugins. The first enabled
DLL owner is `Scavenger Sense`; `Scavenger Sense - SKSE` is disabled. The ESP
remains enabled. No overwrite DLL masks deployment. SMF 3.14 was already enabled;
its runtime files/settings and the game's SKSE installation were not changed.

The deployment script now discovers that enabled owner instead of relying on
its old disabled-folder default. `-PreserveRules` was used. Of 25 pre-existing
installed files, only DLL, Chinese translation and meta.ini version changed.
Five new files add the translation template and four user guides. The personal
INI in overwrite, assigned titles, marker rules, icons, sound, ESP, modlist and
plugins are byte-identical to their backups. No saved settings were migrated
or overwritten merely to demonstrate the new controls.

Backup: `E:\dev\ScavengerSense-backups\2026-10-15-before-0.10` contains the
previous build DLL, complete installed mod, personal INI, profile files and
build/validation/deployment evidence. To roll back the live build, restore
the three changed files from `installed-before/Scavenger Sense`; the added
guides/template are inert and may remain. Revert the development branch for
source rollback. Fully exit and restart Skyrim/SKSE before testing.
