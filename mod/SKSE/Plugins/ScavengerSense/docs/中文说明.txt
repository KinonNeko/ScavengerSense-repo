Scavenger Sense 0.10.1 测试版 — 新功能

0.10.1 复查补修：匹配新版菜单框架的 ImGui 1.90.8 docking 结构定义，
增加启动时版本与布局校验；HUD 隐藏关闭时不再反复重置交互提示的位置。
这一版替代本地 0.10.0 测试包，游戏内效果仍需实测。

一、保留罗盘、消息与字幕
设置页 -> 隐藏界面，开启总开关后，可分别选择隐藏哪些部件。
取消勾选“隐藏罗盘”“隐藏系统消息”“隐藏字幕”即可保留它们。
18 类原版 HUD 部件均有独立开关；HUD 本身仍在运行。
其他 HUD 替换模组的额外部件，可填写其相对 HUDMovieBaseInstance 的路径。
若其他模组隐藏了整个 HUD，本模组的开关不能强行显示其父级。

二、制作其他语言翻译
复制 translations/ScavengerSense_english.ini 到 ScavengerSense.dll 同级，
改名为 ScavengerSense_french.ini 等，语言标识使用小写字母、数字、_ 或 -。
保留 [Translation]，保存为 UTF-8，只翻译等号右侧，左边英文原文不要改。
换行写成字面的 \n，英文键中的等号写成 \=。
进入设置页点“重新扫描语言文件”，即可选择新语言；缺失翻译会回退到英文。
字体必须包含对应文字，框架也要开启对应字形范围。随附中文字体不是万国语言字体。
更完整的说明与增量更新命令见 TRANSLATING.txt。

三、1.7.104 与 DLL 启动错误
已升级 CommonLib 至 12.1.0，并重新编译；修正 1.7.x 被当作 SE 的问题，
支持新版地址库格式，VM 字段也使用版本感知访问器。
用户仍须安装匹配自己游戏版本的 SKSE、Address Library 和菜单框架。
1.6.1170 的泛称“DLL 错误”不能仅凭这一句话判断为同一个问题。
本机更新后的框架仍标为 3.14，已核对全部导入函数及对应的 ImGui 布局。
详见 DEPENDENCIES.txt。

四、安装器中英文
安装第一步选择 English 或简体中文，后续说明跟随切换。
此选项也设置全新安装的菜单语言，但已有个人 INI 的设置仍优先。
中文安装说明保存在源码 fomod/installer_chinese.json，以后打包自动复用。

五、NPC 数字与独立状态条
人物 -> 其他人物 -> NPC 状态条数字，可选当前值、当前/上限、百分比或关闭。
修复了选项原先藏在另一个下拉框事件内部、平时无法正常设置的问题。
状态条样式中可把数字居中放进条内，并调整数字大小。
这里显示资源数值，尚未添加每秒恢复速率数字，也不表示完全替代 TrueHUD 所有功能。

状态条样式 -> 独立状态条与 PNG 皮肤，可分别选择玩家/NPC 和生命/魔法/耐力，
调整各条的长宽倍率、横纵偏移及填充/空条/边框 PNG。
PNG 放在 SKSE/Plugins/ScavengerSense/icons 下面，可使用 skins/ 子目录，
菜单填写相对路径。透明 RGBA PNG 最大 4096×4096。
填充图按数值裁切，背景和边框保持完整大小；缺失填充图回退到内置样式。
图片按原色绘制。想用矩形皮肤时，把共用倾斜设置为 0。
已加载的图片有缓存，原位替换或补上缺失图片后请重启游戏。
更详细的 INI 示例见 CUSTOMISING.txt。

六、唤起火焰与更快触发
旧图标是代码绘制的，所以文件夹里找不到那张“水滴”。
现在内置图标改为多火舌轮廓，并可在扩展菜单指定 PNG 替换。
单击和长按感知原本就有；默认共用键将单击分配给标记、长按分配给清除，
因此不能同时把同一手势交给感知。按键页新增“单击感知”“长按感知”快捷选项，
自动切到独立追踪键布局。单击立即响应，不等待双击间隔。
冲突的追踪绑定会移到中键或取消绑定，手柄用户请检查追踪键。

菜单调整后请保存到 INI。重新安装不会覆盖已有个人 ScavengerSense.ini。
本次无需新开档、BodySlide 或行为生成。离线检查通过不等于游戏内已经实测。
