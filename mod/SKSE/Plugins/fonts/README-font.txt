MainFont.ttf shipped with Scavenger Sense
=========================================

This is Noto Sans SC, unmodified, renamed to MainFont.ttf because that is the
filename SKSE Menu Framework looks for.

  Family     Noto Sans SC
  Version    2.004
  Copyright  (c) 2014-2021 Adobe (http://www.adobe.com/),
             with Reserved Font Name 'Source'
  Licence    SIL Open Font License, Version 1.1 - see OFL.txt beside this file
             http://scripts.sil.org/OFL

The OFL permits bundling and redistributing this font, including with
commercial or free software, provided the licence text travels with it. That
is what OFL.txt is here for. Please keep the two together.

The font is not modified in any way - only the filename differs, and renaming
a file does not create a Modified Version under the licence, so the Reserved
Font Name clause is not engaged.

Coverage: full ASCII and Latin-1, all 6,763 GB2312 hanzi, and CJK punctuation.
Enough for Simplified Chinese item and NPC names. It does NOT cover Japanese
kana, Korean hangul, Cyrillic or Thai - for those, supply your own font with
the right glyphs and point PrimaryFont at it.
